비활성 스킬을 의존성으로 다시 켜지 않는다; 필요한 작업의 스킬만 읽고 이미 읽은 지침은 반복하지 않는다.
단건 조회는 메인이 바로 처리하고 자식·Jev 판단을 붙이지 않는다; 복잡한 작업만 최대 5단계로 계획하고 요청한 변경·필수 검증이 끝나면 멈춘다.
관련 파일·범위만 읽는다; 조회는 head -c 1000을 기본으로 필요시 4000까지 넓히고 실패는 tail -c 4000으로 제한하며 원본 로그·종료코드는 파일로 보존한다.
Jev는 반복 분류·대량 관련성 선별·허용된 반복 UI 선택에 쓴다; 사실·캐시·코드 작성·일회성 분석마다 호출하지 않는다.
의미 판단 5건 이상은 jev-mode batch로 묶는다; 원문은 코드로 읽고 개수·사용량만 출력하며 text_tokens를 Codex 유입량으로 오인하지 않는다.
가까운 필수 검증부터 한 번 수행한다; 변경·실패·명시 요구 없이는 반복하지 않고 선택적 재검증이 애매할 때만 jev-verify를 쓴다.
세션은 짧은 상태·요약부터 확인하고 긴 이력의 관련성 선별에만 jev-session-read를 쓴다; 원문 요구·출처·제약·UNKNOWN을 보존한다.
브라우저는 활성 aside-browser를 우선하고 반복 조작만 jev-action-control에 맡긴다; 실제 픽셀 확인은 지원 도구로 하며 GPT 이미지 생성에 Jev 시각 판정을 붙이지 않는다.
자식은 fork_turns="none"에 범위·완료 조건만 주고 명확한 역할은 설정된 모델·추론 강도로 바로 매핑한다; 혼합 역할만 선택적 workflow advisor에 묻고 사용자 모델을 우선하며 매 단계 Jev·coverage를 강제하지 않는다.
기존 변경·안전 경계·필수 테스트를 보존하고 미확인을 통과로 바꾸지 않는다; 이 Mac의 pip 21.2.4로 PEP 621 설치 금지, 공유 jev-mode·래퍼·키 수정 금지, 허용 설치는 같은 Python import와 실행기 위치로 확인한다.
