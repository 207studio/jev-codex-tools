## 1/4

Jev 토큰 절감을 직접 측정했습니다. 기대보다 작았습니다.

같은 6개 사례를 조건별 두 번 비교:
• Astra 입력 18,975 → 18,705 (-1.4%)
• Astra 출력 92.5 → 54.5 (-41.1%)

좋은 숫자만 고르면 안 되는 결과였습니다.

## 2/4

Jev까지 합친 토큰 수는 오히려 3.9% 늘었습니다. 공급자가 달라 비용·Codex 한도 증감과 같지는 않습니다.

본문은 44.3% 줄였지만 전체 Astra 입력은 1.4%만 줄었습니다. 공통 컨텍스트도 별도로 측정해야겠습니다.

## 3/4

Astra 직접 판단과 코드+Jev 모두 매번 6/6 정답. 코드만 쓴 조건은 4/6 정답, 2건 UNKNOWN이었습니다.

단, 합성 경로 선택 실험입니다. 실제 코드 수정 성공률이나 일반적인 정확도 동등성을 입증한 결과가 아닙니다.

## 4/4

결과를 보고 사례를 바꾸거나 유리한 실행만 골라내지 않았습니다. 전 실행 수치·사례·판정 기준·한계를 공개합니다.
