# 복합 작업의 선택적 실행 계획

단건 조회·명확한 역할은 코드 규칙으로 바로 처리하고 추가 Jev·자식을 붙이지 않는다.
절차 실행·대조는 luna/low, 구현·리뷰는 terra/medium, 충돌 제약 설계는 astra/high를 지원 여부 확인 후 자식 힌트로 쓴다; 사용자 모델을 우선한다.
역할·경로가 모호한 복합 작업에만 `jev-workflow --spec /절대/작업.json --out /절대/새계획.json`을 사용한다. 원문은 넣지 않고 제한된 목적·메타데이터만 넣는다.
동일 계획은 재사용하고 변경된 근거에는 새 context_id를 부여한다; UNKNOWN을 유지하고 추가 재판단을 붙이지 않는다.
계획은 실행 권한·검증 통과 증거가 아니다. 기존 필수 검증을 한 번 수행하고 완료하면 멈춘다.
스키마·기능 플래그·한계는 저장소의 `docs/WORKFLOW_POLICY.md`를 필요한 경우에만 읽는다.
